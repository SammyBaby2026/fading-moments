# 《黑湾账本》卷一审核任务包

## 任务目标

根据《黑湾账本》项目知识库v1.7最新设定，审核**卷一第1-20章重写计划**的逻辑性、剧情商业性和悬疑感。

---

## 项目基本信息

**书名**：《黑湾账本》（The Glass Ledger）
**类型**：权谋悬疑 / 政治惊悚 / 都市黑幕 / 爽文向
**篇幅**：五卷，约25万字
**卷一**：20章，约5万字（正在重写）

---

## 核心设定（v1.7最新）

### 世界观
- **舞台**：虚构西海岸超级城市 San Reina（圣雷纳）
- **核心机制**：The Line / Drop Line（坠落线）
- **核心概念**：Glass Ledger（账本系统）——不是名单，是"处理痕迹管理系统"

### 主要人物

**Iris Kane（第一主角）**
- 身份：独立调查记者
- 核心气质：冷、准、不耐烦
- **卷一人物关系**：
  - 有床伴（《Marrow Ledger》摄影记者，纯身体关系，非灵魂伴侣）
  - 与 Adrian 有暧昧/冲突/温情，但无身体亲密（推迟到卷二）
- **动机**：找姐姐，私人化，不是为了正义

**Grace Kane（姐姐）**
- 状态：处于 private continuity（被系统保留的状态）
- 身份：后半本账的审题人
- 卷一结尾在 Pier 9 现身"验收"Iris

**Adrian Vale**
- 身份：前市长首席危机顾问
- 与 Iris 从互相利用→带账同盟→卷二开始有身体亲密
- **终局**：不洗白，保持旧签字的负担

### 开局线索（第1章）
1. **短信**：Grace照片 + 地址"Pier 9 / Locker 317" + 纸条"Grace从未消失"
2. **实物**：门缝下牛皮纸信封，内藏黄铜钥匙（编号317）
3. **关键细节**：Grace手腕上的旧疤（十三岁玻璃碗留下的）

## 卷一剧情大纲（20章）

### 主线任务
Iris 追查 Gabriel Voss 之死 → 发现 Grace 可能还活着 → 逐步揭开"账本系统"的存在

### 章节分布

**第1-4章：入局**
- 第1章：Voss死亡，匿名包裹（照片+地址+钥匙），床伴出场，女主动机揭示（找姐姐）
- 第2章：Pier 9 / Locker 317，发现 Vita 胸针、腕带（YR-11-2084）、Basement 索引页
- 第3章：Daniel Hurst 车祸，Adrian Vale 首次登场
- 第4章：Iris 直播曝光 Hurst 签字页，被盯上

**第5-8章：深入**
- 第5章：法医 Mara Quinn 展示 2084 真实尸检（restraint bruising）
- 第6章：Adrian 上门给白卡，两人首次深入对话
- 第7章：旧法院档案，发现父亲 E.K. 签名、chamber override
- 第8章：父亲旧楼发现 Basement access review 便笺

**第9-12章：真相初显**
- 第9章：假证人被 SUV 撞死，临死说"不是地下室，是停车楼"
- 第10章：发现 B-layer 真相（Basement 不是物理空间）
- 第11章：Vita 慈善晚宴，Adrian 带 Iris 潜入
- 第12章：拿到 Glass Ledger Q3 Extract，确认是"处理痕迹"

**第13-16章：对抗**
- 第13章：Adrian 被 City Hall 边缘化
- 第14章：Grace 尸检底稿全文揭示
- 第15章：发布会，逼官方承认独立复核正当性
- 第16章：封口令送达，Hurst 音频反击

**第17-20章：卷一高潮**
- 第17章：停车场 Grace 现身，确认活着，给 MCS shard
- 第18章：B-layer 真相确认，Meridian 浮出水面
- 第19章：父亲录像，承认"方法"而非"账本"
- 第20章：Pier 9 姐妹对峙，Grace"验收"Iris，给后半本账目录

## 审核要点

### 1. 逻辑性检查

**人物动机逻辑**
- [ ] Iris 追查姐姐的动机是否充分？（私人化，不是为了正义）
- [ ] 床伴的存在是否合理？（功能性，不影响主线）
- [ ] Iris 与 Adrian 的关系发展是否符合阶段设定？（卷一暧昧不越界）
- [ ] Adrian 帮助 Iris 的动机是否成立？（从控制派转向承担派）

**剧情推进逻辑**
- [ ] 线索递进是否合理？（照片→地址→钥匙→Pier 9→Vita→账本）
- [ ] 每章结尾是否有合理的推进？（cliffhanger 或新发现）
- [ ] 延迟揭示点是否被遵守？（影账 existence 守到卷二）

**系统设定逻辑**
- [ ] Glass Ledger 的概念是否清晰？（处理痕迹，不是名单）
- [ ] Basement/B-layer 的解释是否到位？（处理中间层，不是地下室）
- [ ] Private continuity 状态是否模糊得当？（卷一仅回响，不讲透）

### 2. 剧情商业性检查

**爽点配置**
- [ ] 每章是否有推进？（信息/关系/冲突至少一项）
- [ ] 打脸场景是否足够？（Iris 反制官方/系统）
- [ ] 主角光环是否适度？（对制度语言敏感，但不降智）

**CP线张力**
- [ ] Iris ↔ Adrian 的暧昧是否有足够的"带刺的亲密"？
- [ ] 身体需求（床伴）与情感需求（Adrian）的分离是否清晰？
- [ ] 卷一结尾是否留下足够的期待感？（卷二身体亲密的开始）

**节奏控制**
- [ ] 信息密度是否适中？（不拖沓，也不过度压缩）
- [ ] 松弛点是否合理分布？（卷二较松，卷四最紧）
- [ ] 章尾钩子是否有效？（让读者想继续看）

### 3. 悬疑感检查

**悬念设置**
- [ ] 开局钩子是否够强？（"Grace从未消失"+ 黄铜钥匙）
- [ ] 多层谜团是否清晰？（Grace在哪？Voss怎么死的？账本是什么？）
- [ ] 延迟揭示是否合理？（每章给半步，不给全部）

**氛围营造**
- [ ] 圣雷纳的城市气质是否到位？（冷、制度感、体面下的黑幕）
- [ ] 场景描写是否有"制度空气"？（档案室、慈善晚宴、停车场）
- [ ] 人物对话是否有"人味停顿"？（改口、迟疑、带情绪的拐弯）

**反转铺垫**
- [ ] Grace"验收"Iris 的反转是否有铺垫？
- [ ] 父亲录像的揭示是否震撼但不突兀？
- [ ] 账本真相的揭露是否层层递进？

### 4. 爽文元素检查

**人设爽点**
- [ ] Iris 是否足够"锋利"？（逼近结构问题，不耐烦）
- [ ] 是否有足够的"金手指"？（Grace的线索、Adrian的内部信息）
- [ ] 反派是否有足够的压迫感？（Vivian的气场、系统的冷酷）

**情节爽点**
- [ ] 是否有"打脸"场景？（发布会逼官方承认、直播曝光）
- [ ] 是否有"逆袭"时刻？（从被压制到掌握主动权）
- [ ] 是否有"揭秘"快感？（Basement真相、父亲录像）

**情感爽点**
- [ ] 床戏是否适度？（展示生活状态，不喧宾夺主）
- [ ] 暧昧张力是否足够？（互损中见真情）
- [ ] 姐妹对峙是否有冲击力？（Grace活着，但不是团圆）
